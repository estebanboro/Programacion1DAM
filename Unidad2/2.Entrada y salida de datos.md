## 1. Salida de datos

Para mostrar información por la consola se utiliza la función `System.out.print();` o `System.out.println();` dentro del `main()`.

La diferencia entre ellos es que **`println` hace un salto de línea** después de mostrar el texto; `print` no lo hace, de modo que lo siguiente que se muestre aparecerá en la misma línea.

```java
System.out.print("Hola ");
System.out.print("a todos");
```

```text
Hola a todos
```

```java
System.out.println("Hola");
System.out.println("a todos");
```

```text
Hola
a todos
```

Para visualizar **una cadena de texto**, se escribe entre comillas dobles:

```java
System.out.println("Cadena de texto");
```

Para visualizar **el contenido de una variable**, se utiliza su **identificador**:

```java
System.out.println(num2);
```

📌 **Aclaración:** _en este caso no se muestra el texto «num2», sino **el valor** que almacena la variable `num2`. Si el identificador se escribiera entre comillas, se mostraría literalmente la palabra «num2»._

```java
System.out.println("Hola a todos!");
int precio = 5;
System.out.println(precio);
System.out.println("Precio: " + precio);
```

¿Cómo muestras «Unos calcetines valen 5 euros»? (Obligatorio usar una variable para el valor 5.)

<details>
<summary>💡 Ver solución</summary>

```text
Hola a todos!
5
Precio: 5
```

- `"Hola a todos!"` es un literal `String`: se muestra tal cual.
- `precio` es una variable: se muestra su valor, 5.
- `"Precio: " + precio` concatena (une) el texto y el valor de la variable.

Para el mensaje de los calcetines se concatena un texto, la variable y otro texto:

```java
int precio = 5;
System.out.println("Unos calcetines valen " + precio + " euros");
```

Los espacios dentro de las comillas (`"valen "` y `" euros"`) evitan que el número quede pegado a las palabras.

## 2. Entrada de datos

### 2.1. El objeto Scanner

En las primeras líneas del `main` se declara un objeto de tipo **`Scanner`**. Estas líneas no cambian nunca, por lo que conviene memorizarlas:

```java
Scanner teclado = new Scanner(System.in);
```

Se debe **importar la clase `Scanner`**. Si no se importa, Eclipse marca el error `Scanner cannot be resolved to a type` y propone como solución **Import 'Scanner' (java.util)**, que añade al principio del archivo la línea:

```java
import java.util.Scanner;
```

📌 **Aclaración:** _en esta línea se está declarando una variable de tipo `Scanner` (con **S** mayúscula) cuyo nombre es `teclado`. El nombre puede ser otro (`entrada`, `input`, `sc`…). Conviene que sea corto, porque se escribe muchas veces. El resto de la línea se entenderá más adelante; por ahora basta con memorizarla._

El programa queda así:

```java
import java.util.Scanner;

public class Clase2 {

    public static void main(String[] args) {

        Scanner teclado = new Scanner(System.in);

        // A partir de aquí se puede usar teclado
        // para leer lo que escribe el usuario
    }
}
```

### 2.2. Lectura de datos

Ahora ya se puede usar la variable `teclado` para leer lo que teclea el usuario (una vez que pulsa la tecla **Enter**). Ejemplo de lectura de un entero:

```java
n = teclado.nextInt();
// Cuando el usuario teclee 7 (por ejemplo) y pulse Enter,
// ese 7 se almacena en la variable n.
// Se está asignando a n el entero que se lee de teclado.
```

📌 **Aclaración:** _al ejecutarse `nextInt()`, **el programa se detiene** hasta que el usuario introduce un dato y pulsa Enter; mientras tanto, no se pasa a la siguiente instrucción. Que la consola no muestre nada no significa que el programa no funcione: está esperando la entrada. En Eclipse, mientras el programa se ejecuta, el botón rojo de detener está activo; cuando termina, la consola muestra `<terminated>`._

📌 **Aclaración:** _antes de leer un dato conviene mostrar un mensaje que indique al usuario qué debe introducir. Primero se le informa y después se recoge el dato:_

```java
System.out.println("Introduce un número");
int num = teclado.nextInt();
System.out.println("Has introducido un " + num);
```

```text
Introduce un número
45
Has introducido un 45
```

> ⚠️ **Atención:** al concatenar texto y variables, los espacios deben incluirse dentro de las comillas. Con `"Has introducido un" + num` se obtiene `Has introducido un45`.

> ⚠️ **Atención:** no es posible controlar lo que escribe el usuario. Si introduce un dato de otro tipo (una letra, o un número con decimales cuando se espera un entero), el programa termina con la excepción `InputMismatchException`, que indica que el dato introducido no coincide con el tipo esperado. Más adelante se verá cómo controlar esta situación.

```text
Introduce un número
q
Exception in thread "main" java.util.InputMismatchException
```

📌 **Aclaración:** _en la consola, los números reales se introducen con **coma decimal** (`2,3`) cuando el ordenador está configurado en español; si se escribe `2.3`, se produce `InputMismatchException`. Java almacena el valor y lo muestra con punto (`2.3`)._

### 2.3. Métodos de lectura según el tipo de dato

Se utilizan las funciones:

```java
// Para leer un entero:
int numero1 = teclado.nextInt();

// Para leer un double:
double numero2 = teclado.nextDouble();

// Para leer una cadena de caracteres:
String cadena = teclado.nextLine();

// Para leer un carácter:
char caracter = teclado.next().charAt(0);
```

📌 **Aclaración:** _`nextLine()` lee la siguiente línea completa que escribe el usuario. Para leer un carácter no existe un método específico: `next()` lee la siguiente palabra que escribe el usuario y `charAt(0)` se queda con el carácter de la **posición 0**, es decir, el primero._

### Ejercicio 2

Tarea:

- Pide al usuario que introduzca un número mostrando un mensaje del tipo «Introduce un número».
- Recoge el número que teclea el usuario.
- Muestra un mensaje indicando cuál es el doble de ese número: «El doble de X (el número introducido) es Y».

<details>
<summary>💡 Ver solución</summary>

```java
import java.util.Scanner;

public class DobleNumero {

    public static void main(String[] args) {

        Scanner teclado = new Scanner(System.in);

        System.out.println("Introduce un número");
        int num = teclado.nextInt();
        System.out.println("El doble de " + num + " es: " + num * 2);
    }
}
```

Ejemplo de ejecución (el usuario teclea 7):

```text
Introduce un número
7
El doble de 7 es: 14
```

Se recoge un número por teclado, se hace una operación aritmética (`num * 2`) y el resultado se muestra directamente por pantalla.

Si se quiere admitir números con decimales, se usa un `double`:

```java
double num = teclado.nextDouble();
```

En ese caso, si el usuario teclea `4,5`, se muestra `El doble de 4.5 es: 9.0`.

</details>

<summary>💡 Ver solución</summary>


   El resultado es el mismo; la versión directa ahorra una línea. Es recomendable usar la variable cuando **ese valor se va a necesitar más de una vez**, para no repetir la operación. Si solo se usa una vez, no es necesario almacenarlo.

### 2.4. Problema con Scanner: el buffer

Si primero se lee un entero (o cualquier otro dato que no sea una cadena):

```java
entero = teclado.nextInt();
```

y a continuación se lee una cadena:

```java
cadena = teclado.nextLine();
```

se genera un problema con el **buffer** y **la cadena no se lee**. Para solucionarlo, hay que **vaciar el buffer** antes de leer la cadena:

```java
teclado.nextLine();
cadena = teclado.nextLine();
```

Ejemplo del problema:

```java
System.out.println("Introduce un número");
double num = teclado.nextDouble();
System.out.println("Introduce tu nombre");
String nombre = teclado.nextLine();

System.out.println("Número: " + num);
System.out.println("Nombre: " + nombre);
```

```text
Introduce un número
4
Introduce tu nombre
Número: 4.0
Nombre: 
```

El programa no espera a que se escriba el nombre.

📌 **Aclaración:** _al teclear `4` y pulsar Enter, `nextDouble()` recoge el `4`, pero **el Enter (el salto de línea) queda pendiente de leer**. El siguiente `nextLine()` encuentra ese Enter residual y lo toma como la línea introducida: `nombre` se queda vacío y el programa continúa sin esperar. El `teclado.nextLine();` adicional lee ese Enter y lo descarta; por eso su resultado no se asigna a ninguna variable._

📌 **Aclaración:** _solo hay que vaciar el buffer **justo antes de leer un `String`** cuando lo anterior que se leyó **no era un `String`** (un número, un `char`, un booleano…). Leer un número detrás de otro no da problemas, porque `nextInt()` y `nextDouble()` ignoran ese Enter. Leer dos cadenas seguidas con `nextLine()` tampoco._

```java
System.out.println("Introduce un número");
double num = teclado.nextDouble();
System.out.println("Introduce otro número");
double num2 = teclado.nextDouble();  // Número → número: sin problema
System.out.println("Introduce tu nombre");
teclado.nextLine();                  // Número → String: se vacía el buffer
String nombre = teclado.nextLine();
```

> ⚠️ **Atención:** este problema es muy frecuente. Siempre que se lea un `String` después de un dato de otro tipo, hay que comprobar si es necesario vaciar el buffer.

### Ejercicio 4

- Pide al usuario que introduzca su nombre y recoge el valor.
- Pide al usuario que introduzca su edad y recoge el valor.
- Pide al usuario que introduzca su dirección y recoge el valor (no vacíes el buffer).
- Muestra por pantalla los datos que ha introducido el usuario.
- Vacía el buffer y soluciona el problema.

<details>
<summary>💡 Ver solución</summary>

**Sin vaciar el buffer:**

```java
import java.util.Scanner;

public class DatosUsuario {

    public static void main(String[] args) {

        Scanner teclado = new Scanner(System.in);

        System.out.println("Introduce tu nombre");
        String nombre = teclado.nextLine();
        System.out.println("Introduce tu edad");
        int edad = teclado.nextInt();
        System.out.println("Introduce tu dirección");
        String direccion = teclado.nextLine();

        System.out.println("Nombre: " + nombre);
        System.out.println("Edad: " + edad);
        System.out.println("Dirección: " + direccion);
    }
}
```

Ejemplo de ejecución (el usuario teclea `Ana` y `18`):

```text
Introduce tu nombre
Ana
Introduce tu edad
18
Introduce tu dirección
Nombre: Ana
Edad: 18
Dirección: 
```

El programa no espera a que se introduzca la dirección. Pasar del nombre a la edad no da problemas, porque antes de leer la edad no queda ningún Enter pendiente. El problema aparece entre la edad y la dirección: `nextInt()` deja el Enter sin leer y el `nextLine()` de la dirección lo recoge.

**Vaciando el buffer:** se añade `teclado.nextLine();` justo antes de leer la dirección.

```java
System.out.println("Introduce tu edad");
int edad = teclado.nextInt();
System.out.println("Introduce tu dirección");
teclado.nextLine(); // Se vacía el buffer: se lee el Enter que dejó nextInt()
String direccion = teclado.nextLine();
```

```text
Introduce tu nombre
Ana
Introduce tu edad
18
Introduce tu dirección
Calle Mayor 1
Nombre: Ana
Edad: 18
Dirección: Calle Mayor 1
```

</details>

## Chuleta del Scanner

Resumen de las líneas que se usan siempre con `Scanner`:

```java
import java.util.Scanner;                   // Lo añade Eclipse

Scanner teclado = new Scanner(System.in);   // Al principio del main

System.out.println("Introduce un número");  // 1. Indicar qué se pide
int numero = teclado.nextInt();             // 2. Recoger el dato

teclado.nextLine();                         // Vaciar el buffer (número → String)
String texto = teclado.nextLine();
```
